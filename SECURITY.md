# Segurança e privacidade — CRAS Acolhe

- Nunca inserir dados reais no modo demonstração.
- Nunca publicar `SUPABASE_SERVICE_ROLE_KEY` ou qualquer segredo em código cliente, repositório ou variável `VITE_*`.
- Reportar vulnerabilidades ao responsável técnico do projeto por canal privado; não publicar dados pessoais em issues.
- A migration habilita RLS e não oferece inserção pública de solicitações.
- Adoção com dados reais depende de autorização do controlador, revisão jurídica, avaliação de riscos, definição de bases legais, contratos com operadores e homologação de segurança.
